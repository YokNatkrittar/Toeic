# TOEIC 17

เว็บติว TOEIC 17 วันก่อนสอบ เปิด `index.html` ได้เลย (หรือเปิดผ่าน GitHub Pages)

- **แผนติว** 17 วัน วันละ 60-120 นาที ครบทุกพาร์ต ติ๊กงานที่ทำแล้วได้ (เก็บในเบราว์เซอร์)
- **คำศัพท์** 600 คำ 15 ชุด พร้อมคำแปลไทยและประโยคตัวอย่าง โหมดการ์ด/รายการ ฟังเสียงได้
- **Simulator** ข้อสอบเสมือนจริง 200 ข้อ (Part 1-7) เสียง Listening ใช้ Text-to-Speech ของเบราว์เซอร์ คะแนนแปลงเป็นสเกล 990 แบบประมาณการ
- **เทคนิค** เทคนิคแต่ละพาร์ตและเทคนิควันสอบ

ข้อสอบในชุดนี้เขียนขึ้นใหม่ตามรูปแบบ TOEIC ปัจจุบัน ไม่ใช่ข้อสอบจริงของ ETS

## โครงสร้าง
- `app.html` ส่วนเนื้อหาหน้าเว็บ → `tools/build-index.sh` สร้าง `index.html`
- `data/` คำศัพท์ แผน และข้อสอบ · `js/app.js` ตัวแอป · `js/scenes.js` ภาพ Part 1 · `css/style.css`
